# Hola, soy icemancoin

Domótica, sensores y redes en Tarragona. Monto sistemas que funcionan solos: luces que reaccionan, cámaras que avisan y placas que aguantan meses con una pila. Documento lo que aprendo por el camino, con los comandos y los errores incluidos.

## Con qué trabajo

| Área | Herramientas |
|---|---|
| Domótica | Home Assistant, ESPHome, MQTT, Node-RED |
| Hardware | ESP32, ESP8266, ESP32-CAM, ESP32-C6, Arduino |
| Placas | Raspberry Pi, Orange Pi, Armbian, Linux |
| Redes y servicios | Docker, systemd, SSH, RTSP, Telegram |
| Web | HTML, CSS, JavaScript |

## Proyectos

| Repositorio | Qué encontrarás |

| [domotica_homeassistant_sensoresydispositivos](https://github.com/icemancoin/domotica_homeassistant_sensoresydispositivos) | Cámaras ESP32-CAM y estaciones meteo con ESP8266 y DHT11 en ESPHome |

## En qué estoy ahora

- Ampliando las fichas técnicas de placas y sensores.
- Montajes con ESP32 en deep sleep para sensores de puerta y de temperatura.
- Un panel de control con pantalla táctil para el salón.

## Cómo está escrito esto

Los apuntes son míos y están pensados para consulta rápida. Los datos son orientativos: si vas a cablear algo, comprueba siempre la hoja de datos de tu placa, porque cambia entre revisiones y fabricantes.
